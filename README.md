## How to run
Download the [raw data](https://cs.unibo.it/projects/us-tm2017/static/dataset/raw_data/raw_data.tar.gz) and place in under `data/`

Run the following commands in order
```
docker compose --profile preprocess up --build
docker compose --profile train up --build
```

Generated data is grouped by the full SHA-256 hash of the canonical training
configuration:

```text
data/runs/<config-sha256>/
|-- model.config.yaml
|-- cleaned_data/
|-- transformed_data/
|-- models/
`-- reports/
```

The copied configuration is written with recursively alphabetized mapping keys.
The hash is generated by traversing those keys in order, concatenating their
stringified values, and applying SHA-256. Sensor and feature lists retain their
configured order because that order defines the model input contract.

Preprocessing searches the other hash directories before reading the raw
dataset. Cleaned data can be derived from a saved run whose transport-mode and
sensor configuration is a superset: files are filtered by mode and rows by
sensor. Transformed data can be copied directly when modes and features are
subsets, the sensor set matches, and the window size and step are unchanged;
only the current feature columns are written. If direct transformed reuse is
not valid, the pipeline reuses compatible cleaned data and applies the current
transformation. Each derived directory contains `reuse.json` identifying its
source run. With no compatible saved run, preprocessing proceeds from the raw
dataset as usual.

## Development container

Open this project directory in VS Code and run **Dev Containers: Reopen in Container**. The development service bind-mounts the project at `/app`, installs the pipeline requirements during the image build, and installs the configured editor tools after the container is created.

The same service can be verified from a terminal:

```sh
docker compose build dev
docker compose up -d dev
docker compose exec dev python -c "import pandas, sklearn, skl2onnx, yaml"
docker compose down
```

## Notes
Running the following command:
```
docker compose --profile preprocess up --build
```

is equivalent to running the following commands sequentially:

```
docker compose --profile extract up --build
docker compose --profile clean up --build
docker compose --profile transform up --build
```
